# Download-a-story Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stories after the first are downloaded on demand into a runtime cache, with library card states, a quota check and an honest offline page, so the catalogue can pass the precache line.

**Architecture:** Per-story Vite chunks and asset folders; a build plugin emits `story-assets.json`; Workbox precaches the shell and first story and runtime-caches `assets/stories/**` into a `stories` cache; a `downloads` module store drives the library cards; the player loads a story's chunk before rendering.

**Tech Stack:** Vite 8 (rolldown), vite-plugin-pwa 1.3 / Workbox, React 18, vitest + happy-dom, sharp for covers.

**Spec:** `docs/superpowers/specs/2026-09-19-download-a-story-design.md`

## Global Constraints

- No network calls at runtime other than the app's own hashed assets; no analytics.
- Tap targets >= 64 px; Calm mode unaffected; hash routing unchanged.
- Coverage thresholds in `vitest.config.ts` hold or rise; no AI attribution in commits.
- Budgets: JS gzip <= 100 KB; precache <= 6 MB after this change; largest downloadable story <= 3 MB.

## Roast (before code)

- **Architect (4):** a hand-kept list of a story's files would drift the first time a scene borrows a cutout from another story (storm already borrows from jonah, creation and david). Killed by deriving the list from the bundle's own chunk metadata, transitively through shared chunks; the spike showed storm's chunk listing david's birds.
- **Architect (4):** the library rendered every story's cover scene live, so lazy chunks would either load all of them (no saving) or leave blank cards offline. Pivot: static cover images, generated by a script and committed, with a data test that each story has one.
- **Architect (3):** a `stories` cache written by the page and read by Workbox must use the same key. Workbox `CacheFirst` matches request URLs against the named cache; the page writes `cache.put(url, response)` with the same absolute URL. Verified in the browser check, not assumed.
- **Architect (3):** `navigator.storage.estimate()` is missing on old WebKit and optimistic on iOS (a large quota, then eviction). Treat a missing API as unknown and allow; treat an estimate below the story size as no space; record iOS eviction as an owner device test.
- **Buyer (3):** a child taps Download. Harmless (no cost, no account) but confusing if it fails silently. Every failure has a visible state and a retry, and the row is separate from the card so a mis-tap does not open the story.
- **Buyer (2):** cards lose their idle animation. Accepted: the card is small, the stage is where richness matters, and the library's first paint gets lighter.
- **CFO (2):** no API cost; a few hundred KB of covers join the precache. Cheap.
- **Verdict:** proceed-with-changes: derived file lists, static covers, visible failure states.
