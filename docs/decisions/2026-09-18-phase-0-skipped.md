- **Reason given:** local churches have already requested the product.

  (children's work, Sunday groups). Price points, parent demand and the

    including classroom display rights) is decided; 2b (tablet letterbox)
    is done.

    Family time before generating the Life of Jesus collection, so the
    churches' actual asks shape phase 4.

    now the only planned learning channel; it matters more, not less.

  script and write-up template serve the pilot's observed sessions.
